# CODLYTIC — Galaxy Portfolio

A cinematic, space-inspired portfolio for Nitesh, presenting data analytics, machine learning, Python and SQL as an interactive galaxy.

## Features
- Animated starfield and nebula background
- CSS 3D-style orbiting planets
- Responsive project cards and navigation
- About and contact sections
- Lightweight HTML, CSS and JavaScript — no build step required

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site.

## Customize
Update the project cards with verified project repository/demo links, add your resume link, and replace the contact email before sharing publicly.
