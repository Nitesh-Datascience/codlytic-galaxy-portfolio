## Run locally
Open `index.html` in a browser to view the static portfolio. The AI guide requires the Vercel API deployment and a Gemini API key configured on the server.

## Deploy
The project is configured for Vercel with `vercel.json` and the `api/chat.js` serverless function. Connect this GitHub repository to Vercel and deploy the `main` branch. Add `GEMINI_API_KEY` (or `gemini_api_key`) in Vercel Project Settings → Environment Variables for the AI guide, then redeploy after changing the variable.

Do not put the Gemini API key in frontend code or commit it to GitHub.
